# frontend-system-design-fundamentals

A repo to learn and practice the fundamentals of frontend system designs

## How to use this repo

This repo does not use any bundler or frameworks. So opening `index.html` in
chrome is enough to explore and checkout the exercise output.

## Overview

Here we are going to learn and practice the latest frontend system design
supported in modern browsers like Chrome, Firefox etc.

### Exercises

1. `1-dom-operation`: Basic DOM operations and understanding uses of `<template>` tag.
